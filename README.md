# Sistema de Locação de Veículos

Sistema em Java para gestão de frota e locação de veículos, desenvolvido na disciplina de Programação Orientada a Objetos - segundo período (UniCEUB).

## Conceitos aplicados
- Classes abstratas
- Herança
- Polimorfismo
- Encapsulamento

## Como executar
1. Clone o repositório: `git clone https://github.com/thuts071/sistema-locacao-veiculos.git`
2. Compile: `javac -d bin src/*.java`
3. Execute: `java -cp bin Main`

## Funcionalidades
- (O sistema fo feito para registrar novos locatários, novos veículos e o preço do aluguel. Como o objetivo era aprender a desenvolver com classes abstratas, algumas funções não são editáveis pelo usuário, como o preço da locação.)
